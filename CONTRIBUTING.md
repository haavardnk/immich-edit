# Contributing

Before changing code, read:

- [Development](https://haavardnk.github.io/immich-edit/development/)
- [Architecture](https://haavardnk.github.io/immich-edit/architecture/)
- [Render pipeline](https://haavardnk.github.io/immich-edit/pipeline/) for pixel or shader changes

## Pull requests

- Match the existing code and UI patterns.
- Add focused tests for changed behavior.
- Update public documentation in the same commit as user-visible behavior, routes, configuration,
  storage, or render defaults.
- Run the validation commands for the changed area.
- Include local GPU evidence for shader, GPU pass, device, or CPU/GPU parity changes.
- Use a conventional commit title under 50 characters.

Use [GitHub Issues](https://github.com/haavardnk/immich-edit/issues) for bugs and feature requests.
Ask contributor questions in
[GitHub Discussions](https://github.com/haavardnk/immich-edit/discussions).
Report security problems through [GitHub Security Advisories](SECURITY.md), not a public issue.
