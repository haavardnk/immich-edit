Deployment

Use the Docker image (haavardnk/immich-edit, Linux amd64/arm64, UID/GID 10001) for Linux servers. On macOS, run natively to use Metal.

Image tags

Section titled “Image tags”
  • X.Y.Z — pinned release (recommended for production)
  • X.Y, X, latest — newest stable release
  • edge — latest main build that passed CI (not for production)

Reverse proxy

Section titled “Reverse proxy”

Keep immich-edit on loopback or a private Docker network and terminate TLS with a reverse proxy. Forward Host, X-Forwarded-For, and X-Forwarded-Proto. The backend trusts those headers only from peers in TRUSTED_PROXIES (defaults to loopback and private ranges; see Configuration).

HTTPS for the installed app

Section titled “HTTPS for the installed app”

Installing immich-edit as a PWA (and running its service worker) requires a trusted HTTPS certificate — plain http:// LAN addresses and clicked-through self-signed certs cannot install:

  • Tailscale Serve: tailscale serve --bg 3000 provides trusted HTTPS inside your tailnet.
  • Caddy tls internal: install Caddy’s root CA on each client device (on iOS/iPadOS also enable it in Settings > General > About > Certificate Trust Settings).

If you put an auth proxy (such as Cloudflare Access) in front of immich-edit, allow /manifest.webmanifest, /apple-touch-icon.png, /favicon.svg, /icon-192.png, /icon-512.png, and /icon-maskable-512.png without login so iOS/iPadOS receives the app icon.

Health checks

Section titled “Health checks”
Endpoint Auth Purpose
GET /api/health/live None Liveness probe (used by Docker HEALTHCHECK)
GET /api/health Session Renderer, Immich, DB, codec, and redacted config state
GET /api/immich/ping Session 204 when Immich responds; 502/504 otherwise
